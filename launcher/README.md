# Map Launcher（ミニマルな3Dマップ型ホームランチャー）

スマホのホーム画面として使うことを想定した、**3Dの街を歩いてアプリを開く**ランチャーのプロトタイプです。
起動するとデフォルトで3Dマップが表示され、街を歩いて目的のアプリの建物にたどり着くと「開く」ボタンが出ます。

## 通信量とサイズ

外部ライブラリ・CDN・地図タイルを一切使いません。街も看板も端末側で生成します。

| | 無圧縮 | gzip |
| --- | --- | --- |
| 初回の読み込み（HTML+CSS+JS） | 約 101 KB | 約 33 KB |
| アイコン画像（初回のみ） | 約 10 KB | 約 7 KB |
| **合計** | **約 110 KB** | **約 40 KB** |
| 2回目以降 | 0（Service Worker のキャッシュから起動） | 0 |

three.js（同梱で 720 KB）は使わず、必要な機能だけの WebGL レンダラー（`src/gl.js` / 19 KB）を自前で持っています。
街の静的な部分は1本の頂点バッファにまとめてあるので、1フレームの描画コマンドは 30 回程度です。

## 構成

```
launcher/
├─ index.html              画面（HUD・パネル）
├─ app.css                 スタイル（スマホ縦画面前提・セーフエリア対応）
├─ src/
│  ├─ gl.js                自前の WebGL レンダラー（行列・ジオメトリ・シェーダー）
│  ├─ main.js              初期化・メインループ・カメラ・ナビゲーション
│  ├─ world.js             街の生成（地面・道・街区・建物・看板・木・街灯）
│  ├─ player.js            アバターの移動と当たり判定
│  ├─ controls.js          タッチ操作（スティック／視点／ピンチ／タップ）
│  ├─ apps.js              アプリ定義・保存・起動処理
│  ├─ ui.js                HUD・ミニマップ・一覧・編集フォーム
│  └─ sky.js               時刻に連動した4つのパレット（夜・朝・昼・夕）
├─ manifest.webmanifest    ホーム画面追加用（全画面起動）
└─ sw.js                   オフラインキャッシュ
```

## 動かす

ES モジュールを使っているので、`file://` ではなく HTTP で開いてください。

```bash
cd launcher
python3 -m http.server 8000
# → http://localhost:8000/ をスマホのブラウザで開く
```

GitHub Pages などに置けば、そのままスマホから開けます。
Chrome / Safari の「ホーム画面に追加」をすると、全画面（アドレスバーなし）で起動します。

## 操作

| 操作 | 動き |
| --- | --- |
| 画面左側をドラッグ | バーチャルスティックで歩く |
| 画面右側をドラッグ | 視点を回す（上下で俯瞰角） |
| 2本指ピンチ | ズーム |
| 地面をタップ | その場所まで自動で歩く |
| 建物をタップ | その建物へ案内（地面に矢印の道が出る） |
| ミニマップをタップ | タップした場所へ歩く |
| アプリをさがす | 一覧・検索。選ぶとその建物まで案内 |
| ⌂ | 中央広場（ホーム）に戻る |
| 建物の入口に近づく | 下に「開く」カードが出る → タップで起動 |

## 見た目の方針（ミニマル）

- 紙のような無彩色の地面と白い建物。**色はアプリの色だけ**（屋上のスラブと看板の点）
- 装飾はできるだけ持たない：窓・テクスチャ・影の焼き込みなし、木は単色のコーン
- 文字情報は看板（白いピル）とHUD（白いピル）に集約
- 時刻に連動して4つのパレットを補間。夜は街全体を暗いティントで落として、看板と街灯だけが光る
- HUD は 上＝時計と現在地／下＝「さがす」＋2つの丸ボタン のみ

## 街の構成

中央広場から5方向に道が伸び、それぞれの街区にアプリの建物が建っています。

- つながり区（SNS・メッセージ）
- しごと区（仕事・学び）
- たのしみ公園（動画・音楽・ゲーム）
- くらし通り（買い物・お金・生活）
- どうぐ横丁（ツール・ユーティリティ）

## アプリの追加・編集

「アプリをさがす」→「編集」でアプリをタップすると編集、「＋ 追加」で新規追加できます。
設定できる項目は 名前 / アイコン（絵文字）/ 色 / 街区 / URLスキーム / Web版URL / 建物の高さ。
内容は `localStorage` に保存され、設定パネルから JSON で書き出し・読み込み・初期化ができます。

### アプリの起動について

Web アプリからネイティブアプリを開くには **URL スキーム** を使います。
まずスキーム（例 `line://`）を試し、開けなかった場合は Web 版 URL にフォールバックします。

- スキームは端末・アプリのバージョンによって変わります。開けない場合は正しいスキームを設定してください。
- Android Chrome では `intent://...#Intent;scheme=...;package=...;end` 形式も指定できます。
- iOS Safari はスキームの成否を JavaScript から判定できないため、フォールバックが誤動作することがあります。
- ブラウザからは「カメラアプリを開く」のような OS 機能の直接起動はできません。

## 軽さのために入れてある設定

- **描画品質**（設定パネル）：`きれい`=devicePixelRatio 2 まで / `ふつう`=1.5 まで / `軽量`=1（省電力）
- 看板は距離でフェード（近すぎ・遠すぎるものは描かない）
- 街は起動時に1度だけ生成し、以降は同じバッファを使い回す

## 本物のホームランチャーにする場合

ブラウザ／PWA では OS のホーム画面そのものを置き換えることはできません（ホームボタンで戻る先にはできない）。
同じ体験をネイティブで作る場合は、この街の設計（街区・看板・ナビ）をそのまま移植できます。

1. Android アプリとして `AndroidManifest.xml` に `android.intent.category.HOME` + `DEFAULT` を持つ Activity を用意する
2. `PackageManager.queryIntentActivities()` でインストール済みアプリとアイコンを取得し、`apps.js` の代わりのアプリ一覧にする
3. 3D 描画は Filament / SceneView などに置き換える（`world.js` の生成ロジックがそのまま設計図になります）
4. アプリ起動は `startActivity(launchIntent)`（URL スキーム不要・全アプリ起動可能）
5. `onNewIntent` でホームボタン押下時に中央広場へ戻す

iOS はホーム画面の置き換えができないため、ショートカット的な単体アプリ（またはこの PWA）が上限になります。
